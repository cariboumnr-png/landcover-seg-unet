# Experiment & Artifacts Directory Tree Layout

This document defines the canonical filesystem directory structure for input datasets,
pipeline artifacts, and session execution results under an experiment root directory (`<exp_root>`).

> [!NOTE]
> **Data Generation Notice**: The repository does **not** ship with real-world
> geospatial datasets or proprietary satellite imagery. To populate a local testing
> environment with a complete set of synthetic sample GeoTIFFs, run:
> ```bash
> python scripts/generate_dummy_data.py
> ```
> This script uses the central `dummy_geotiff_factory` to generate the mock dataset
> tree shown in the `input/` folder below. Executing the project pipelines against this
> input tree populates the corresponding `artifacts/` and `results/` subdirectories.

> [!TIP]
> **Pipeline Decoupling & Isolation**:
> - **`data-harmonize` (ETL)**: Reads unharmonized GeoTIFFs from `input/raw/` and
> outputs reprojected Virtual Rasters into `artifacts/harmonized_data/`.
> - **Downstream Pipelines (`data-ingest`, `data-prepare`, `model-train`)**: Consume
> pre-aligned GeoTIFFs from `input/data/` or harmonized VRT outputs from `artifacts/harmonized_data/`.
> - **Isolation**: Executing `data-harmonize` does **not** overwrite or interfere with `input/data/`,
> allowing all pipelines to be run and tested independently without strict prerequisite coupling.

```text
<exp_root>/                                      # Default: ./experiment/
│
├── input/                                       # Generated by scripts/generate_dummy_data.py
│   │
│   ├── raw_data/                                # Raw raster inputs & manifest sidecars (ETL)
│   │   ├── manifest.json                        # Central dataset manifest
│   │   ├── sample_dev_sentinel2.tif             # 10-band optical feature composite (EPSG:32618)
│   │   ├── sample_dev_sentinel2.json
│   │   ├── sample_dev_dem.tif                   # 1-band float32 elevation DEM (EPSG:32618)
│   │   ├── sample_dev_dem.json
│   │   ├── sample_dev_landcover.tif             # Categorical landcover label mask (EPSG:32618)
│   │   ├── sample_dev_landcover.json
│   │   ├── sample_dev_leadspc.tif               # Categorical tree species label mask (EPSG:32618)
│   │   ├── sample_dev_leadspc.json
│   │   ├── sample_domain_1.tif                  # Categorical domain context map
│   │   └── sample_domain_1.json
│   │
│   ├── reference_raster/                        # Spatial extent and AOI reference rasters
│   │   ├── sample_extent.tif                    # Spatial boundary reference GeoTIFF (EPSG:3161)
│   │   └── sample_test_aoi.tif                  # Test Area of Interest GeoTIFF (EPSG:3161)
│   │
│   └── utm_rasters/                             # Cross-UTM rasters for mosaic utility testing
│       ├── image_17n.tif                        # Feature raster in UTM zone 17N (EPSG:32617)
│       ├── image_18n.tif                        # Feature raster in UTM zone 18N (EPSG:32618)
│       ├── label_17n.tif                        # Label raster in UTM zone 17N (EPSG:32617)
│       └── label_18n.tif                        # Label raster in UTM zone 18N (EPSG:32618)
│
├── artifacts/                                   # Generated by Pipeline Execution
│   │
│   ├── world_grids/                             # Produced by 'world-grid' pipeline
│   │   ├── grid_row_<srow>_<orow>_col_<scol>_<ocol>.json
│   │   └── grid_report.json                     # World grid execution summary report
│   │
│   ├── harmonized_data/                         # Produced by 'data-harmonize' pipeline
│   │   ├── harmonization_runs.json              # Cumulative harmonization run ledger
│   │   └── run_0001/                            # Serialized ETL run directory
│   │       ├── harmonized_<name>.vrt            # Reprojected single-source Virtual Raster
│   │       ├── harmonized_features_STACKED.vrt  # Canonical multi-channel stacked feature Virtual Raster
│   │       ├── harmonized_labels_STACKED.vrt    # Canonical multi-channel stacked label Virtual Raster
│   │       ├── valid_pixel_mask.vrt             # 1-band boolean valid-pixel mask Virtual Raster
│   │       ├── harmonize_report.json            # Harmonization execution summary report
│   │       └── config.json                      # Harmonization configuration record
│   │
│   ├── ingested_data/                           # Produced by 'data-ingest' pipeline
│   │   ├── ingestion_runs.json                  # Cumulative ingestion run ledger
│   │   ├── block_windows.json                   # Grid-aligned spatial window index manifests
│   │   ├── run_0001/                            # Serialized batch run directory
│   │   │   ├── ingest_report.json               # Ingestion execution summary report
│   │   │   ├── collisions.json                  # Inter-batch spatial collision ledger
│   │   │   └── config.json                      # Ingestion configuration record
│   │   ├── domain_knowledge/                    # Canonical domain rasters & tiles pool
│   │   │   ├── <domain_name>.json
│   │   │   └── <domain_name>_tiles_<gid>.npz
│   │   └── data_blocks/                         # Canonical dataset blocks pool (pre-split)
│   │       ├── blocks/                          # Extracted unnormalized block arrays
│   │       ├── catalog.json                     # Cumulative dataset block catalog & lineage
│   │       └── schema.json                      # Dataset block structural schema & block_identity
│   │
│   └── prepared_data/                           # Produced by 'data-prepare' pipeline
│       ├── train_blocks/                        # Prepared training array blocks
│       ├── val_blocks/                          # Prepared validation array blocks
│       ├── test_blocks/                         # Prepared testing array blocks
│       ├── block_splits_source.json
│       ├── block_splits_summary.json
│       ├── block_splits_prepared.json
│       ├── label_stats.json
│       ├── image_stats.json
│       ├── schema.json
│       ├── prep_report.json                     # Preparation execution summary report
│       └── config.json                          # Preparation configuration record
│
├── results/                                     # Produced by 'model-train' / 'model-evaluate'
│   └── run_0001/                                # Serialized experiment run directory
│       ├── checkpoints/
│       │   ├── status.json                      # Training phase status tracking
│       │   ├── <name>_best.pt                   # Best model checkpoint weights
│       │   └── <name>_last.pt                   # Final model checkpoint weights
│       ├── logs/                                # Training run execution logs
│       ├── plots/                               # Metric and diagnostic visualization plots
│       ├── previews/                            # Model output prediction previews
│       ├── config.json                          # Fully resolved execution configuration
│       ├── evaluation.json                      # Evaluation metrics JSON (if evaluation run)
│       ├── summary.json                         # Overall run summary metrics JSON
│       └── step_results.json                    # Per-step loss/metric tracking JSON
│
└── preflight/                                   # Produced by 'command=preflight' validation
    └── preflight_report_<uid>.json              # Pre-flight readiness diagnostic report JSON

* Note: Grid and domain artifacts are stored as single-file self-contained
  JSON envelopes (see ADR-0063).
```
